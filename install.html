iOSiPhone 安装步骤
  1. 用 Safari 打开上面的链接（或扫码后点开）。
  2. 点击底部中间的「分享」按钮（方框带向上箭头）。
  3. 向上滑动，选择「添加到主屏幕」。
  4. 点「添加」，应用图标即出现在主屏，点开即全屏运行、可离线。
Android安卓安装步骤
  1. 用 Chrome 打开上面的链接（或扫码后点开）。
  2. 地址栏右侧会出现「安装应用 / 添加到主屏幕」图标，点击它。
  3. 确认「安装」，桌面即生成应用图标。
  4. 若未弹出提示：点右上角 ⋮ 菜单 →「安装应用」。
提示：数据保存在本机浏览器中。换手机或清缓存前，请在应用内「数据管理 → 导出」备份。
